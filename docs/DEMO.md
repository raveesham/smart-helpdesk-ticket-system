# Manager demo script (8–10 minutes)

1. Explain the Help Desk business problem and architecture (30 sec).
2. Log in as user; create ticket and show generated ticket ID (1 min).
3. Log in as agent; assign ticket, add comment, update status (1 min).
4. Show admin dashboard and role-based menus (1 min).
5. Show Git commit and Jenkins pipeline stages (1 min).
6. Explain SAST/SCA/secret/image scanning results (2 min).
7. Show Docker images and Kubernetes pods/services (1 min).
8. Open application through port-forward and verify ticket workflow (1 min).
9. Show Grafana pod CPU/memory/restarts and Prometheus targets (1 min).
10. Close with security gates, rollback, and next improvements (30 sec).

Only show successful results actually produced by your environment. If a stage is not implemented,
state it as future work rather than presenting a mock result.
